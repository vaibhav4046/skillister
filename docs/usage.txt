skillister - find, route, and install agent skills across any agent CLI

USAGE
  skillister <command> [args]

COMMANDS
  index                 Build the skill index from every detected host CLI
  find <query>          Rank installed skills against a query
  route <prompt>        Show which skills a prompt should trigger
  packs                 List registry packs (and what was deliberately left out)
  install <pack-id>     Print the install path for a pack, from its own upstream repo
  wrapper add <id> <url> [ref]
                        Register a repo that Claude Code cannot add directly
  init [host]           Wire skillister into a host CLI (default: claude-code)
  stats                 Index breakdown by collection
  doctor                Check the install and report problems

EXAMPLES
  skillister index
  skillister find supply chain dependency risk
  skillister route "the login page is broken"
  skillister install trailofbits
  skillister doctor

ENVIRONMENT
  SKILLISTER_HOME         Where the index lives (default: ~/.skillister)

The index is disk truth. If a skill is not in it, it is not installed.
